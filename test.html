Documento di Test per Conversione HTML a Word

Questo è un documento completo progettato per testare la conversione da HTML a Word. Include vari elementi di formattazione e struttura.

1. Formattazione del Testo

Il testo può essere formattato in diversi modi:

  • Grassetto per enfatizzare concetti importanti
  • Corsivo per citazioni o termini stranieri
  • Sottolineato per evidenziare
  • Testo evidenziato con sfondo giallo
  • Testo importante in rosso e grassetto
  • Codice inline con font monospazio

2. Liste

Lista non ordinata:

  • Primo elemento

Lista ordinata:

  1. Fase uno: Preparazione
  2. Fase due: Esecuzione
  3. Fase tre: Verifica
  4. Fase quattro: Completamento
